# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a Vulnerability

Open8086 runs entirely in the user's browser or as a local client-side developer tool with zero external network tracking or remote server calls.

If you find a security issue or vulnerability (e.g. potential DOM-based XSS when loading untrusted `.asm` files), please open an issue in the GitHub repository or contact the maintainers. We appreciate responsible disclosure and aim to resolve all valid reports promptly.
